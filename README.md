# 🚀 DevTracker

DevTracker is a smart, fully client-side developer roadmap and course tracking application. It empowers developers and students to stay organized by isolating roadmaps across different disciplines, visualizing progress via Kanban boards, and generating intelligent learning paths directly from PDF and DOCX files using the Groq API.

## ✨ Features

* **Isolated Roadmaps**: Manage multiple independent roadmaps (e.g., Web Development, Graphic Design, AI) without overwriting data.
* **AI-Powered Generation**: Upload PDF, DOCX, or TXT files and automatically generate structured roadmaps using Groq API (`llama-3.3-70b-versatile`).
* **Dynamic Kanban Board**: Drag & Drop task management across To Do, In Progress, and Done columns.
* **Course Progress Module**: Visual milestone tracking, phase completion, and achievement badges.
* **WhatsApp Integration**: Get instant notifications on task completion.
* **Dynamic UI System**: Sidebar, footer, and stack updates based on active roadmap.
* **Fully Client-Side**: Works entirely offline using `localStorage` (no backend required).

## 💻 How to Run Locally

### Option 1: Direct Run

1. Download or clone repository
2. Open `index.html`
3. Run in browser

### Option 2: VS Code Live Server (Recommended)

1. Open folder in VS Code
2. Install **Live Server extension**
3. Click **Open with Live Server**

---

## 🔑 Initial Setup

1. Open **Settings**
2. Paste your Groq API Key
3. Click **Save Key**
4. Start generating roadmaps instantly
